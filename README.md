# JW Retro Deck v1.5.0

Flat GitHub Pages-ready PWA.

## Highlights
- Premium purpose-built game-library interface
- Local multi-system ROM bank using IndexedDB
- Automatic platform recognition and cover matching
- EmulatorJS launcher with repaired touch controls, including Start and Select
- My Abandonware catalogue metadata search for title matching
- Built-in Snake and Table Tennis

Upload the contents of this ZIP to the repository root. Existing locally stored ROMs remain in the browser database for the same site origin.
